# ⏱️ FocusSpace — Pomodoro & Ambient Workspace

FocusSpace is a productivity web application built with React. It combines a classic Pomodoro countdown timer with procedural ambient nature sounds and tab visibility tracking to help users stay focused during deep work sessions.


## ✨ Key Features

* **Pomodoro Timer:** Built-in work and break intervals with start, pause, and reset controls.
* **Procedural Nature Sound Generator:** Synthesizes custom ambient background audio in real-time using the Web Audio API without downloading external audio files.
* **Distraction Tracker:** Monitors tab switches and active user engagement using the Page Visibility API to encourage focus accountability.
* **Modern Dark UI:** Responsive layout tailored for a distraction-free experience.


## 🛠️ Tech Stack

* **Frontend:** React.js, JavaScript (ES6+)
* **Build Tool:** Vite
* **Styling:** CSS3
* **Web APIs:** Web Audio API, Page Visibility API
